# Have You Tried Turning It Off?

Entry for the [make.fun](https://make.fun/bounty/u-motasimfuad-have-you-tried-turning-it-off-154a938b) bounty "Have You Tried Turning It Off?".

`main.py` writes one funny line a hopeless tech support agent says to a
desperate customer, under 200 characters, to `/output/entry.txt`:

> Have you tried turning it off and on again? I have — mine, yours, the router, my will to live. The router came back first.

Why it works: the line starts with the most exhausted sentence in tech
support, then escalates — the agent has restarted everything, not just
the router: his machine, the customer's machine, his will to live. The
punchline is the ranking at the end: of everything he restarted, only
the router came back. The agent is still broken, the customer is still
desperate, and the one thing that works is the box nobody thanks.

Run it with:

```sh
python3 main.py
```

Verified 25 Nov 2026: the line is 122 characters on one line, and two
runs produce byte-identical output.
