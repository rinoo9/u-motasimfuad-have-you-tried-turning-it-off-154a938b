# Have You Tried Turning It Off?

Entry for the [make.fun](https://make.fun/bounty/u-motasimfuad-have-you-tried-turning-it-off-154a938b) bounty "Have You Tried Turning It Off?".

`main.py` writes one funny line a hopeless tech support agent says to a
desperate customer, under 200 characters, to `/output/entry.txt`:

> I turned it off and on again — the Wi-Fi came back, the printer filed for divorce, and your password is still just 'password'.

Why it works: the agent followed the script perfectly — power-cycle
everything — and the network genuinely came back, so the first clause
sounds like a success story. Then the printer stops being a device and
starts being a spouse walking out, and the password turns out to be the
single laziest word a customer can pick. The agent fixed the connection
while the household fell apart, and he reports the divorce in the same
flat, professional tone as the Wi-Fi coming back.

Run it with:

```sh
python3 main.py
```

Verified 26 Nov 2026: the line is 126 characters on one line, and two
runs produce byte-identical output.
